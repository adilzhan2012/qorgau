# Qorgau — акустический мониторинг леса

Прототип системы охраны особо охраняемых природных территорий. Датчики на
базе ESP32-S3 слушают лес и сами решают, что слышат и опасно ли это:

| Класс | Что это | Для парка |
|---|---|---|
| **Природа** | листва, ветер, вода, дождь | безопасно |
| **Птицы, звери** | пение, крики | безопасно |
| **Тишина** | фон, ничего заметного | безопасно |
| **Собака** | лай — рядом человек | **опасно** |
| **Транспорт** | двигатель машины, мотоцикла | **опасно** |
| **Бензопила** | незаконная рубка | **опасно** |
| **Выстрел** | браконьеры | **опасно** |

— с процентами уверенности и объяснением, почему принято такое решение.
Опасный звук — это тревога на карте и красный светодиод на плате.

Живая карта датчиков, обновление в реальном времени, распознавание работает
без интернета и без облачных ИИ-сервисов. Устройства добавляются прямо на
карте; плата, подключённая по USB, сама находит своё устройство по ID.

### ▶ Открыть сайт: https://adilzhan2012.github.io/qorgau/

Ничего скачивать и устанавливать не нужно — откройте ссылку в **Chrome или Edge**
и нажимайте кнопки со звуками. Чтобы подключить плату, нажмите
«Подключить плату ESP32» — один раз, дальше она подключается сама.

Собрать плату, прошить, подключить GPS и выложить всё на GitHub — пошагово

## Главная идея

**Никаких нейросетей и облаков: семь классов — это семь наборов признаков
с весами, и каждый вердикт можно объяснить.**

ESP32-S3 снимает звук с микрофона (INMP441 или ICS-43434), считает быстрое
преобразование Фурье и вытаскивает из каждого кадра 22 числа:

| Признак | Что означает |
|---|---|
| `rms` | громкость, дБFS |
| `zcr` | частота переходов через ноль — высокая у шипения, низкая у гула |
| `attack` | насколько резко нарос звук — у выстрела почти 1 |
| `harmonic` | есть ли у звука высота тона — у двигателя есть, у выстрела нет |
| `flatness` | «шумность» спектра: 1 — белый шум, 0 — чистый тон |
| `spread` | размазана ли энергия по спектру |
| `bands[16]` | энергия в 16 логарифмических полосах от 60 Гц до 8 кГц |

По этим числам плата **сама** решает, что это за звук, и шлёт вердикт вместе
с признаками. Тот же классификатор, строка в строку, живёт и на сайте
(`src/lib/audio/classify.ts`): он разбирает звук с микрофона ноутбука и файлы,
а вердикт платы показывает рядом — расхождение было бы видно, а не спрятано.

Вердикт — это несколько байт. Именно поэтому схема рассчитана на LoRaWAN:
передавать сам звук не нужно, и датчик может годами работать от батареи.

## Как это устроено

```
ESP32-S3 + микрофон I2S + GPS
   I2S 16 кГц, кадры по 1024 отсчёта (64 мс)
   → БПФ 1024 → 16 полос + громкость, ZCR, атака, высота тона, шумность, разброс
   → классификатор → вердикт (класс, %, опасно?) + светодиод
   → строка JSON в USB Serial (115200): признаки, вердикт, GPS
                    ↓
   браузер (Web Serial) ─┐
   микрофон ноутбука ────┼→ тот же классификатор в браузере → карта и карточки
   проигрывание файла ───┘
```

Один набор признаков, один классификатор в двух копиях (C на плате, TypeScript
на сайте), три источника звука. Сервера нет, поэтому сайт можно открыть по ссылке.

Сервера нет вообще: сайт — это статические файлы, а классификация считается
в браузере. Поэтому его можно открыть по ссылке на любом ноутбуке.

**Новых зависимостей — ноль.** БПФ и чтение COM-порта написаны вручную,
чтобы перед демонстрацией ничего не пришлось устанавливать.

## Запуск у себя (не обязательно)

Сайт уже опубликован по ссылке выше, и для демонстрации этого достаточно.
Локальный запуск нужен, только если хотите менять код:

```bash
npm install
npm run dev
```

Открыть **http://localhost:3100** в **Chrome или Edge** — Web Serial есть
только в них.

**Ключей, аккаунтов и базы данных не нужно.** Список устройств хранится в
браузере, распознавание считается там же.

## Устройства

Кнопка **+** над списком: название, ID и точка на карте — кликом по карте,
геолокацией ноутбука или координатами. В карточке устройства — изменить,
переставить, удалить, журнал тревог.

Статус честный: **В сети** — только у того, что присылает звук прямо сейчас,
**Тревога** — когда классификатор уверен, остальные — **Нет сигнала**.
Последние показания и тревоги помнятся между перезагрузками.

Список, показания и журнал лежат в localStorage этого браузера.

### Проверить, что классификатор действительно работает

Страница **[/selftest](https://adilzhan2012.github.io/qorgau/selftest/)** синтезирует восемь звуков с заранее
известными ответами — от тишины и водопада до выстрела — и показывает, что
классификатор решил и почему. Сейчас — 8 из 8. Сигналы генерируются заново
при каждом обновлении страницы.

## Три способа показать распознавание

| Способ | Как | Когда использовать |
|---|---|---|
| **Кнопки со звуками** | Панель «Датчики» → Выстрел / Собака / Бензопила | Самый надёжный, не зависит от шума и железа |
| **Микрофон ноутбука** | Кнопка «Микрофон ноутбука», разрешить доступ | Самый живой: хлопок в ладоши → «Выстрел» |
| **ESP32 по USB** | «Подключить плату ESP32», выбрать порт | Настоящее железо |

Плата представляется по ID (`{"id":"QRG-003",...}`) и попадает в устройство с
таким же ID; незнакомый ID становится новым устройством на карте. ID можно
записать в плату с сайта — он хранится во флеше, перепрошивать не нужно.
Порт выбирается один раз: дальше Chrome открывает его сам при каждом
подключении. Плат может быть несколько.

Подробная пошаговая инструкция с подключением платы и разбором ошибок —
в **[DEMO.md](DEMO.md)**.

### Свои звуки

Положить `.wav` или `.mp3` в `public/audio/` и запустить `npm run audio` —
кнопки появятся сами, код менять не надо. Класс определяется по имени файла:
`gunshot`, `dog`/`лай`, `chainsaw`/`пила`, `vehicle`/`машина`, `ambient`/`лес`.

Файлы в комплекте синтезированы тем же скриптом; свои записи он не
перезаписывает.

## Железо

| Компонент | Роль |
|---|---|
| **ESP32-S3** (N8R2) | слушает, считает признаки, читает GPS |
| **INMP441** или **ICS-43434** | цифровой I2S-микрофон — любой из двух, распиновка одинаковая |
| **GPS-модуль** с UART (NEO-6M, NEO-M8N, ATGM336H…) | координаты датчика; необязателен |

Микрофон: `VDD→3V3`, `GND→GND`, `L/R→GND`, `SCK/BCLK→GPIO4`, `WS/LRCL→GPIO5`,
`SD/DOUT→GPIO6`. GPS: `VCC→3V3`, `GND→GND`, `TX→GPIO18`, `RX→GPIO17`
(последний можно не подключать). Пины меняются `#define`-ами в начале скетча.
**Не используйте GPIO 33–37** — на S3 они заняты PSRAM.

Плата шлёт координаты раз в две секунды, и устройство **само встаёт на карту**,
как только GPS поймал спутники. Встроенный RGB-светодиод показывает вердикт
без ноутбука: зелёный — безопасно, красный — опасно, жёлтый мигает — GPS ищет
спутники. Схема с картинкой и разбор состояний — в
[DEMO.md](DEMO.md#схема-подключения).

Прошивка при старте сама проверяет микрофон и пишет в порт, что именно не так
с подключением, если что-то не так — результат виден и на сайте.

Заряд батареи плата шлёт, если в скетче задан `PIN_BATTERY` (делитель 1:1
с Li-ion на ADC-пин). На USB заряд не измеряется, и сайт показывает «—», а не
выдуманное число.

> **Arduino UNO для этой задачи не подходит.** У ATmega328P нет блока I2S,
> 2 КБ оперативной памяти и 16 МГц — БПФ на 1024 точки туда не поместится,
> а INMP441 — цифровой микрофон по I2S. Слушает только ESP32-S3.

Скетч: [`firmware/qorgau_sensor/qorgau_sensor.ino`](firmware/qorgau_sensor/qorgau_sensor.ino).
Собирается и на ядре ESP32 2.x, и на 3.x — версия I2S-драйвера выбирается
автоматически.

## Где данные

Всё — в браузере того ноутбука, где открыт сайт: список устройств
(`qorgau.devices.v1` в localStorage), последние показания, журнал тревог и
привязки плат. Сервера и облака нет, ключей и аккаунтов не требуется —
склонировал, `npm install`, `npm run dev`.

Для настоящего парка с сотней датчиков этот слой меняется на любую базу:
хук `useDeviceStore` — единственное место, которое знает, где лежит список.

## Карты

MapLibre GL, не Mapbox — ни токена, ни аккаунта. Три бесплатных стиля в
`src/lib/mapStyles.ts`: тёмный (Esri Dark Gray Canvas), спутник (Esri World
Imagery) и рельеф (OpenTopoMap).

Подпись об источнике тайлов внизу слева убирать нельзя — это условие
лицензии. Для продакшена стоит взять MapTiler, Stadia или Mapbox: Esri не
публикует явной открытой лицензии на эти адреса.
