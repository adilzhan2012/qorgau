# Qorgau — как показать прототип

Короткая шпаргалка на день демонстрации. Подробности архитектуры — в конце.

---

## 1. Открыть сайт

### https://adilzhan2012.github.io/qorgau/

Просто откройте ссылку в **Chrome или Edge** (Web Serial есть только там).
Ничего устанавливать не нужно — ни на своём ноутбуке, ни на чужом.

Сайту не нужен ни интернет-сервер, ни база данных: список устройств хранится
в браузере, распознавание считается прямо в нём же. Единственное, что нужно
от сети — загрузить саму страницу и картинки карты.

Статус на карте честный: **«В сети»** горит только у устройства, которое
прямо сейчас что-то присылает; **«Тревога»** — когда классификатор уверен;
всё остальное — **«Нет сигнала»**. Ничего не рисуется заранее.

---

## 2. Устройства на карте

При первом открытии на карте шесть точек в Иле-Алатау — это обычные записи,
их можно переименовать, переставить или удалить. Свои добавляются кнопкой
**+** над списком: название, ID (подставляется сам: QRG-007, QRG-008…) и
точка — **«Указать на карте»** (клик по карте), **«Я здесь»** (геолокация
ноутбука) или координаты руками.

В карточке устройства: **Изменить**, **Переставить** (ткнуть новое место на
карте), **Удалить**. Ниже — журнал тревог: что, когда, с какой уверенностью
и почему.

Всё это хранится в браузере на этом ноутбуке и переживает перезагрузку.

## 3. Три способа показать распознавание

### А. Кнопки со звуками — самый надёжный

В панели «Датчики» выбрать устройство в списке «Микрофон и файлы →
устройство», нажать кнопку со звуком. Звук играет через колонки, сайт его
разбирает, появляется вердикт с процентами, пометкой «безопасно / опасно» и
объяснением. На опасном звуке устройство на карте краснеет.

| Кнопка | Что должно получиться |
|---|---|
| Листва на ветру, Водопад | Природа · безопасно |
| Птица | Птицы, звери · безопасно |
| Лай собаки | Собака · **опасно** |
| Машина | Транспорт · **опасно** |
| Бензопила | Бензопила · **опасно** |
| Выстрел | Выстрел · **опасно** |

Водопад — самый показательный: громкий, широкополосный, по спектру похож на
выстрел, но ровный. Классификатор смотрит на атаку и не путает.

Не зависит ни от шума в классе, ни от железа. Начинать показ лучше с этого.

### Б. Микрофон ноутбука — самый живой

Нажать **Микрофон ноутбука**, разрешить доступ. Теперь ноутбук работает как
выбранное устройство: хлопок в ладоши даёт «Выстрел», ровный гул —
«Транспорт», звук с телефона — соответствующий класс. Проценты меняются в
реальном времени.

Этим хорошо отвечать на «а если я сам издам звук?».

### В. ESP32-S3 с микрофоном INMP441 — настоящее железо

1. Подключить плату по USB.
2. **Закрыть Монитор порта в Arduino IDE** — COM-порт держит только одна
   программа, и если монитор открыт, браузер порт не получит.
3. На сайте нажать **Подключить плату ESP32**, выбрать порт в окне Chrome.
4. Плата появится в панели «Платы по USB» с числом кадров и вердиктом.

Дальше всё само:

- **Порт выбирается один раз.** Chrome запоминает разрешение: при следующем
  открытии сайта или когда плату воткнули заново, она подключается без
  клика.
- **Плата находит своё устройство по ID.** Если плата представляется как
  `QRG-003`, её звук идёт в устройство `QRG-003`. Если такого устройства
  нет — оно **создаётся само** в центре карты; откройте его и нажмите
  «Переставить».
- **ID можно записать в плату с сайта.** В строке платы выберите нужное
  устройство, откройте его карточку и нажмите **«Записать … в плату»**. ID
  сохраняется во флеше платы — перепрошивать не нужно, и на любом другом
  ноутбуке она сразу найдёт своё место.
- **Плат может быть несколько** — каждая на своё устройство.

## 4. Прошивка платы

Файл: `firmware/qorgau_sensor/qorgau_sensor.ino`

### Схема подключения

```
                         ESP32-S3
                     ┌──────────────┐
   INMP441 /         │              │          GPS (NEO-6M, M8N,
   ICS-43434         │              │          ATGM336H — любой NMEA)
  ┌────────┐         │              │         ┌────────┐
  │ VDD ───┼──────── 3V3         3V3 ─────────┼─── VCC │
  │ GND ───┼──────── GND         GND ─────────┼─── GND │
  │ L/R ───┼──────── GND      GPIO18 ◄────────┼─── TX  │
  │ SCK ───┼──────► GPIO4      GPIO17 ────────┼──► RX  │ (можно не подключать)
  │ WS  ───┼──────► GPIO5         │           └────────┘
  │ SD  ───┼──────► GPIO6         │
  └────────┘         │            │
                     │   USB ─────┼──── ноутбук (питание + данные)
                     └──────────────┘
```

#### Микрофон: INMP441 или ICS-43434

Это два поколения одного и того же цифрового I2S-микрофона, у модулей
одинаковые шесть ножек и одинаковое подключение. Подходит **любой**.

| Модуль | ESP32-S3 |
|---|---|
| VDD | 3V3 |
| GND | GND |
| L/R | GND (левый канал) |
| SCK (BCLK) | GPIO4 |
| WS (LRCL) | GPIO5 |
| SD (DOUT) | GPIO6 |

Ножка `L/R` выбирает один из двух слотов I2S, и в каком именно окажутся
данные — зависит от микрофона и версии драйвера (в интернете на этот счёт
спорят). Прошивка поэтому читает **оба** слота и сама берёт тот, где есть
сигнал: `L/R` можно посадить хоть на GND, хоть на 3V3. В Мониторе порта при
старте будет `OK: микрофон работает, слот 0` (или 1).

Если хочется подключить оба микрофона сразу — на **одну и ту же** шину (SCK,
WS, SD общие), `L/R` у них разный; плата возьмёт тот, что громче при старте.

Если распаяно иначе — поменять `PIN_BCLK`, `PIN_LRCL`, `PIN_DOUT` в начале скетча.

#### GPS

Любой модуль с четырьмя ножками и NMEA на 9600 бод (заводская скорость у всех
перечисленных).

| Модуль | ESP32-S3 | Зачем |
|---|---|---|
| VCC | 3V3 | у большинства модулей стоит свой стабилизатор и 5V тоже подойдёт, но логика у них 3,3 В — на 3V3 надёжнее |
| GND | GND | |
| TX | **GPIO18** | модуль *говорит*, плата *слушает* — это самое важное соединение |
| RX | GPIO17 | плата модулю ничего не шлёт, можно оставить в воздухе |

Пины меняются строками `PIN_GPS_RX` / `PIN_GPS_TX`; `PIN_GPS_RX -1` отключает
GPS совсем.

**Первый захват спутников — 1–5 минут под открытым небом** (у окна — дольше,
в глубине комнаты — никогда). На модуле обычно есть светодиод: замигал раз в
секунду — захват есть. На сайте в карточке устройства видно: «модуль молчит»
(проверьте TX→GPIO18), «ищет спутники · видно 3», «8 спутников» + координаты.

Как только есть захват, **устройство само встаёт на карту**: для устройства,
которое создала плата, это включено сразу; для добавленного вручную — тумблер
«Координаты с GPS» в карточке или кнопка «Переставить по GPS один раз».
Маркер не дёргается от шума GPS: сдвиг меньше 8 м не учитывается.

#### Светодиод

Встроенный RGB-светодиод платы (GPIO48 на ESP32-S3-DevKitC-1, на некоторых
платах GPIO38 — поправьте `PIN_LED`) показывает вердикт без ноутбука:

| Цвет | Что значит |
|---|---|
| зелёный | безопасный звук: природа, птицы, звери |
| синий, тусклый | тишина |
| **красный** | опасный звук — держится 8 секунд, как тревога на сайте |
| жёлтый, мигает | GPS подключён, но спутники ещё не пойманы |

Тревога — только когда опасный класс продержался несколько кадров подряд:
для выстрела четыре (четверть секунды), для лая пять, для мотора и пилы
восемь. Один дрогнувший кадр — это щелчок или дверь, а не браконьер. Сайт
считает так же.

#### Какие пины на S3 нельзя

GPIO 33–37 заняты PSRAM, GPIO 19–20 — это USB, GPIO 0/45/46 — режим загрузки.
Всё, что выбрано выше, свободно.

### Настройки Arduino IDE

> **Сначала надо поставить поддержку ESP32** — сейчас её в вашей Arduino IDE нет,
> установлены только AVR и ESP8266. Файл → Настройки → «Дополнительные ссылки для
> менеджера плат» → добавить
> `https://espressif.github.io/arduino-esp32/package_esp32_index.json`,
> затем Инструменты → Плата → Менеджер плат → найти **esp32** → Установить.
> Скачивание занимает несколько минут — **сделайте это заранее, не в классе.**

| Пункт | Значение |
|---|---|
| Плата | ESP32S3 Dev Module |
| USB CDC On Boot | **Enabled** (иначе Serial не виден) |
| PSRAM | OPI PSRAM |
| Порт | ваш COM-порт |

Скетч собирается и на ядре 2.x, и на 3.x — версия I2S-драйвера выбирается
автоматически.

### Проверка

Открыть Монитор порта на **115200**. Сначала плата представится:

```json
{"hello":"qorgau","fw":"1.5","id":"QRG-001","mic":"ok (слот 0)"}
```

затем пойдут строки:

```json
{"id":"QRG-001","rms":-52.3,"zcr":0.31,"attack":0.02,"harmonic":0.09,"flatness":0.81,"spread":0.94,"top":"nature","conf":87,"danger":false,"bands":[...]}
```

и раз в две секунды — строка про GPS:

```json
{"gps":{"fix":false,"sats":3}}
{"gps":{"fix":true,"lat":43.056130,"lng":76.984810,"sats":8,"hdop":1.1,"alt":1650}}
```

`{"gps":{"fix":false,"seen":false}}` значит, что от модуля не пришло ни байта:
проверьте TX модуля → GPIO18 и питание.

Если вместо этого повторяется `{"error":"I2S не запустился..."}` — перепроверьте
провода микрофона. Что нашла проверка микрофона, видно и на сайте в карточке
устройства.

### Команды плате

Сайт шлёт их сам, но из Монитора порта можно и руками:

| Строка | Что делает |
|---|---|
| `{"get":"hello"}` | плата представляется |
| `{"set":{"id":"QRG-007"}}` | новый ID во флеш; действует сразу и после перезагрузки |

### Батарея

По умолчанию плата на USB и заряд не измеряет — на сайте у неё «—».
Для автономной точки: делитель 1:1 с плюса Li-ion на ADC-пин, в скетче
`PIN_BATTERY 1`. Тогда в каждой строке появится `"bat":NN`, а на карточке —
проценты.

### Если браузер не открывает порт

Чаще всего порт держит Монитор порта в Arduino IDE — закройте его, сайт
скажет об этом сам. Web Serial есть только в Chrome и Edge.

## 5. Что отвечать на вопросы

**«Где здесь искусственный интеллект?»**
Плата измеряет звук: громкость, резкость нарастания, высоту тона, «шумность»
спектра, пик к среднему, центр тяжести спектра и энергию в 16 полосах — 26
чисел с каждого кадра в 64 мс. Дальше главное: решение принимается не по
кадру, а по последним полутора секундам. За 64 мс лай, капля и выстрел
неразличимы, а за полторы секунды видно поведение звука — держится он или
прерывается, скачет ли громкость, сколько было резких начал. По этим числам
плата сама решает, что слышит: семь классов, у каждого свой набор признаков с
весами. Не нейросеть, а объяснимая модель: под каждым вердиктом написано,
какой признак его вытянул.
Тот же классификатор работает и на сайте — для микрофона ноутбука и файлов.

**«Что считается опасным?»**
Лай собаки, машина, бензопила, выстрел — всё, где рядом человек, которого в
заповеднике быть не должно. Природа (листва, ветер, вода), птицы и звери,
тишина — безопасно. На плате это ещё и светодиод: зелёный / красный.

**«Как именно оно отличает выстрел от лая?»**
Показать строку «Почему» под вердиктом — там перечислены признаки, которые
сработали. У выстрела это резкий удар, хлопок короче паузы и пик много выше
фона; у лая — отдельные выкрики с паузами, энергия в полосе 0.4–3 кГц и
голос, а не щелчок; у бензопилы — непрерывность, устойчивая высота тона и
неподвижный спектр. Часть этих признаков обязательна: бензопилы без
непрерывного звука не бывает, сколько бы ни совпало остального.

**«А это точно работает, а не записано заранее?»**
Открыть страницу **/selftest** — классификатор прогоняется на восьми
синтезированных сигналах с заранее известными ответами, и видно, по каким
признакам принято решение. Сигналы генерируются заново при каждом обновлении.
Либо включить микрофон и предложить учителю самому издать звук.

**«А на настоящих записях, а не на своих же?»**
`npm run corpus` скачивает 170 полевых записей (ESC-50: собаки, бензопилы,
двигатели, дождь, гроза, птицы, капель), `npm run eval` печатает, сколько было
ложных тревог и пропусков — сейчас 79 % верных вердиктов, 23 ложные тревоги,
15 пропусков, и в отчёте видно, какие именно. Каждая запись проверяется ещё и
в испорченном виде: тише, издалека, под шум леса и под ветер. Цифры в README
взяты оттуда, а не придуманы.

**«Почему не Arduino UNO?»**
У UNO нет блока I2S, 2 КБ оперативной памяти и 16 МГц. Микрофон INMP441 —
цифровой, по I2S, а быстрое преобразование Фурье на 1024 точки в 2 КБ не
поместится. Поэтому слушает ESP32-S3, а UNO в этой схеме не нужен.

**«Где хранятся данные? Это работает без интернета?»**
Работает полностью офлайн. Список датчиков с координатами, последние показания
и журнал тревог лежат в браузере этого ноутбука, распознавание считается на нём
же. Облако для прототипа не нужно и не подключено.

**«Что будет в настоящем лесу?»**
Вместо USB — LoRaWAN: по радио уйдёт только вердикт (класс, процент, флаг
опасности) — несколько байт, что с запасом укладывается в ограничения LoRa;
признаки нужны только для отладки. Звук передавать не нужно, поэтому
устройство может годами работать от батареи.

## 6. Свои звуки

Положить `.wav` или `.mp3` в `public/audio/`, запустить `npm run audio` и
запушить — кнопки появятся на сайте сами. Класс определяется по имени файла:
`gunshot`, `dog`/`лай`, `chainsaw`/`пила`, `vehicle`/`машина`, `ambient`/`лес`.

Файлы в комплекте синтезированы командой `npm run audio`; свои записи их не
перезаписывают.

## 7. Как это устроено

```
ESP32-S3 + микрофон I2S + GPS
   I2S 16 кГц, кадры по 1024 отсчёта (64 мс)
   → БПФ 1024 → 16 полос + громкость, ZCR, атака, высота тона, шумность, разброс
   → классификатор → вердикт (класс, %, опасно?) + светодиод
   → строка JSON в USB Serial (115200): признаки, вердикт, GPS
                    ↓
   браузер (Web Serial) ─┐
   микрофон ноутбука ────┼→ тот же классификатор в браузере → карта и карточки
   проигрывание файла ───┘
```

Один набор признаков, один классификатор в двух копиях (C на плате, TypeScript
на сайте), три источника звука. Сервера нет, поэтому сайт можно открыть по ссылке.

| Файл | Зачем |
|---|---|
| `firmware/qorgau_sensor/` | прошивка: звук по I2S, GPS по UART, команды с сайта |
| `src/lib/audio/features.ts` | измерение признаков кадра |
| `src/lib/audio/classify.ts` | **классификатор** — здесь крутить пороги |
| `src/lib/live/readings.ts` | вердикт по признакам + защёлка тревоги |
| `src/hooks/useReadings.ts` | показания, журнал тревог, память между сессиями |
| `src/hooks/useDeviceStore.ts` | список устройств в localStorage |
| `src/hooks/useBoards.ts` | платы по USB: автоподключение, привязка по ID, GPS |
| `src/lib/audio/serialSensor.ts` | Web Serial: чтение кадров, команды плате |
| `src/app/selftest/page.tsx` | проверка классификатора |

Новых зависимостей нет ни одной: БПФ и чтение порта написаны вручную,
чтобы ничего не пришлось устанавливать перед демонстрацией. Сайт — статические
файлы, поэтому он открывается по ссылке на любом компьютере.
