## 1. Что нужно

### Железо

| Что | Зачем | Примечание |
|---|---|---|
| **ESP32-S3-DevKitC-1** (N8R2 или N16R8) | сама плата | у платы два USB-разъёма, нужен тот, что подписан **USB** (не UART) |
| **INMP441** или **ICS-43434** | цифровой I2S-микрофон | подходит любой из двух, распиновка одинаковая |
| **NEO-6M** (или NEO-M8N, ATGM336H) | GPS-модуль | любой с четырьмя ножками и NMEA на 9600 бод; необязателен — без него плата работает, просто не знает, где стоит |
| Кабель USB-C (или micro-USB — смотря что на плате) | питание + данные | **обязательно с линиями данных** — кабель «только зарядка» плата не увидит |
| Провода Dupont «мама–мама» ×10 | соединить | |
| Макетная плата | по желанию | удобно, но можно и на проводах |

### Программы на ноутбуке

| Что | Откуда |
|---|---|
| **Arduino IDE 2.x** | https://www.arduino.cc/en/software |
| **Node.js 20+** (нужен только чтобы запускать сайт у себя) | https://nodejs.org |
| **Git** | https://git-scm.com/download/win |
| Браузер **Chrome** или **Edge** | сайт открывает COM-порт через Web Serial — Firefox и Safari не умеют |

## 2. Собрать плату

Плата обесточена (USB вынут), пока подключаете провода.

```
                         ESP32-S3
                     ┌──────────────┐
   INMP441 /         │              │          GPS (NEO-6M, M8N,
   ICS-43434         │              │          ATGM336H — любой NMEA)
  ┌────────┐         │              │         ┌────────┐
  │ VDD ───┼──────── 3V3         3V3 ─────────┼─── VCC │
  │ GND ───┼──────── GND         GND ─────────┼─── GND │
  │ L/R ───┼──────── GND      GPIO18 ◄────────┼─── TX  │
  │ SCK ───┼──────► GPIO4      GPIO17 ────────┼──► RX  │ (можно не подключать)
  │ WS  ───┼──────► GPIO5         │           └────────┘
  │ SD  ───┼──────► GPIO6         │
  └────────┘         │            │
                     │   USB ─────┼──── ноутбук (питание + данные)
                     └──────────────┘
```

### Микрофон

| Ножка модуля | ESP32-S3 |
|---|---|
| VDD | 3V3 |
| GND | GND |
| L/R | GND (или 3V3 — неважно, прошивка сама найдёт, в каком слоте сигнал) |
| SCK (BCLK) | GPIO4 |
| WS (LRCL) | GPIO5 |
| SD (DOUT) | GPIO6 |

### GPS

| Ножка модуля | ESP32-S3 | Важно |
|---|---|---|
| VCC | 3V3 | у большинства модулей есть свой стабилизатор и 5V тоже подойдёт, но логика у них 3,3 В — 3V3 надёжнее |
| GND | GND | |
| **TX** | **GPIO18** | модуль *говорит*, плата *слушает*. Самая частая ошибка — перепутать TX и RX |
| RX | GPIO17 | плата ничего не шлёт модулю, можно оставить в воздухе |

> У NEO-6M антенна — квадратная керамическая нашлёпка на проводе.
> Она должна смотреть в небо и лежать не на металле.

### Что нельзя трогать на ESP32-S3

GPIO 33–37 заняты PSRAM, GPIO 19–20 — это USB, GPIO 0/45/46 — режим загрузки.
Все пины выше свободны. Если у вас распаяно иначе — в начале скетча
`firmware/qorgau_sensor/qorgau_sensor.ino` есть строки `#define PIN_*`,
поменяйте там.

## 3. Установить Arduino IDE и поддержку ESP32

Делать **заранее** — скачивание ядра ESP32 занимает несколько минут и ~1 ГБ.

1. Поставить Arduino IDE 2.x, запустить.
2. **Файл → Настройки → «Дополнительные ссылки для менеджера плат»** —
   вставить:
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
   OK.
3. **Инструменты → Плата → Менеджер плат** — в поиске набрать `esp32`,
   найти **esp32 by Espressif Systems**, нажать **Установить**. Подождать.
4. Библиотек ставить не надо: прошивка использует только то, что входит в
   ядро ESP32 (I2S, HardwareSerial, Preferences, NeoPixel-светодиод через
   RMT). GPS разбирается своим парсером NMEA, TinyGPS++ не нужен.

## 4. Прошить плату

1. Подключить плату в разъём **USB** (не UART) кабелем с данными.
2. Открыть `firmware/qorgau_sensor/qorgau_sensor.ino` в Arduino IDE.
3. **Инструменты** — выставить:

   | Пункт | Значение |
   |---|---|
   | Плата | **ESP32S3 Dev Module** |
   | USB CDC On Boot | **Enabled** — иначе Serial не будет виден |
   | PSRAM | **OPI PSRAM** (у N8R2 / N16R8 память есть) |
   | Порт | **ваш COM-порт** — см. ниже |

4. Нажать **→ Загрузка**. В окне «Вывод» должно закончиться строкой
   `Hard resetting via RTS pin...` или `Leaving...`.

### Какой порт выбрать

В **Инструменты → Порт** плата ESP32-S3 выглядит как
`COM5 (ESP32S3 Dev Module)` или `USB JTAG/serial debug unit (COM5)` —
номер у вас будет свой. Посмотреть можно и без IDE: Диспетчер устройств →
**Порты (COM и LPT)**.

**COM1 — это не плата.** Это встроенный последовательный порт материнской
платы, он есть всегда, даже если ничего не подключено. Если в списке только
COM1 — Windows плату не видит.

### Если не работает

| Что пишет | Причина | Что делать |
|---|---|---|
| `Could not open COM1, the port is busy or doesn't exist` | выбран COM1 — порт материнской платы, платы нет | смотрите ниже «плата не появляется» |
| В списке портов только COM1 или список пуст | плата не появляется | 1) другой кабель — с данными, не «только зарядка»; 2) разъём **USB**, не UART; 3) другой USB-порт компьютера, без хаба; 4) зажать **BOOT**, нажать **RESET**, отпустить BOOT — плата войдёт в режим загрузчика и появится как «USB JTAG/serial debug unit» |
| `the port is busy` при правильном порте | порт держит другая программа | закрыть Монитор порта в IDE и вкладку сайта, где плата подключена. COM-порт может держать только одна программа |
| `Failed to connect to ESP32-S3: Wrong boot mode` | плата не вошла в загрузчик | зажать BOOT, нажать RESET, отпустить BOOT, повторить загрузку |
| `A fatal error occurred: ... Timed out waiting for packet header` | плохой кабель или порт | другой кабель / другой USB-порт |
| Компиляция падает с `i2s.h` / `driver/i2s_std.h` | не то ядро | скетч собирается на ядре 2.x и 3.x — проверьте, что выбрана плата **ESP32S3 Dev Module**, а не ESP32 Dev Module |

## 5. Проверить плату в Мониторе порта

**Инструменты → Монитор порта**, скорость **115200**. Нажать RESET на плате.

Сначала плата проверяет микрофон и пишет, что нашла:

```
OK: микрофон работает, слот 0
{"hello":"qorgau","fw":"1.4","id":"QRG-001","mic":"ok (слот 0)"}
```

Потом ~15 раз в секунду — признаки звука и вердикт:

```json
{"id":"QRG-001","rms":-52.3,"zcr":0.31,"attack":0.02,"harmonic":0.09,"flatness":0.81,"spread":0.94,"top":"nature","conf":87,"danger":false,"bands":[...]}
```

Хлопните в ладоши — `rms` подскочит. Значит, микрофон живой.

И раз в две секунды — строка про GPS:

| Строка | Что значит |
|---|---|
| `{"gps":{"fix":false,"seen":false}}` | от модуля не пришло **ни байта** — проверьте TX модуля → GPIO18 и питание |
| `{"gps":{"fix":false,"sats":3}}` | модуль отвечает, видит 3 спутника, захвата ещё нет — ждите |
| `{"gps":{"fix":true,"lat":43.056130,"lng":76.984810,"sats":8,"hdop":1.1,"alt":1650}}` | есть координаты |

Светодиод на плате: **зелёный** — безопасный звук, **красный** — опасный
(8 секунд), **синий тусклый** — тишина, **жёлтый мигает** — GPS ищет спутники.

### Если не работает

| Что видно | Что делать |
|---|---|
| Пусто, ничего не печатает | скорость не 115200; или USB CDC On Boot был Disabled — поменять и перепрошить |
| `{"error":"I2S не запустился..."}` | перепроверить шесть проводов микрофона, особенно SCK/WS/SD |
| `mic":"silent"` / «микрофон молчит» | SD не подключён, или VDD не на 3V3 |
| Кракозябры | скорость не та |

**Перед тем как подключать плату к сайту, Монитор порта надо закрыть.**

## 6. Подключить плату к сайту

Сайт: https://adilzhan2012.github.io/qorgau/ (или свой, см. раздел 8).
Только **Chrome** или **Edge**.

1. Закрыть Монитор порта в Arduino IDE.
2. На сайте в панели **«Датчики»** нажать **«Подключить плату ESP32»**.
3. Браузер покажет список портов — выбрать тот же COM, что в IDE.
4. Плата представится, и в списке устройств появится карточка с её ID
   (`QRG-001`). Статус — «В сети», ниже — живой спектр и вердикт.

Это делается **один раз**: браузер запоминает порт, и дальше плата
подключается сама при открытии сайта (и переподключается, если её выдернуть
и вставить).

### Переименовать плату

В карточке устройства — поле ID. Новое имя (`QRG-007`) плата запишет во
флеш и будет представляться им и после перезагрузки.

### Если не работает

| Что | Что делать |
|---|---|
| Кнопки «Подключить плату» нет / серая | не Chrome/Edge, или сайт открыт по `http://` не с localhost — Web Serial работает только на `https://` и `http://localhost` |
| Порта нет в списке браузера | плату не видит Windows — раздел 4, «плата не появляется» |
| «Не удалось открыть порт» | порт занят Монитором порта в IDE или другой вкладкой — закрыть |
| Карточка появилась, но «Нет сигнала» | плата не шлёт строки — открыть Монитор порта (закрыв сайт) и посмотреть раздел 5 |

## 7. GPS: поставить устройство на карту

1. Вынести плату **под открытое небо** (у окна — дольше, в глубине комнаты —
   никогда). Первый захват холодного NEO-6M — **1–5 минут**. На модуле
   загорится/замигает светодиод раз в секунду — захват есть.
2. В карточке устройства на сайте состояние GPS меняется:
   «модуль молчит» → «ищет спутники · видно 3» → «8 спутников» + координаты.
3. Устройство, которое **создала плата**, встаёт на карту само — у него сразу
   включён тумблер **«Координаты с GPS»**.
4. Устройство, которое вы **добавили вручную** и потом привязали к плате, на
   месте: включите в его карточке «Координаты с GPS» или нажмите
   «Переставить по GPS один раз».

Маркер не дёргается от шума GPS: сдвиг меньше 8 м не учитывается.

### Если не работает

| Что | Причина |
|---|---|
| «модуль молчит» | TX модуля не на GPIO18 (перепутаны TX/RX — самое частое), или VCC/GND не подключены. На модуле не горит светодиод питания — нет питания |
| «ищет спутники · видно 0» больше 5 минут | нет неба: помещение, металл над антенной, антенна отключена |
| «видно 3–4», фикса нет | мало спутников, ещё подождать или отойти от стен |
| Координаты есть, а на карте не двигается | у устройства выключен тумблер «Координаты с GPS» |

## 8. Запустить сайт у себя

Не обязательно — опубликованная версия работает и так. Нужно, если вы
меняете код.

```bash
git clone https://github.com/adilzhan2012/qorgau.git
```

```bash
cd qorgau
```

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:3000 (порт напишет в консоли). Правки в коде
подхватываются сами, без перезапуска.

Полезное:

| Команда | Что делает |
|---|---|
| `npm run typecheck` | проверить типы — запускать перед коммитом |
| `npm run build` | собрать статический сайт в `out/` |
| `npm run audio` | пересоздать тестовые звуки в `public/audio/` |
| `npm run deploy` | опубликовать на GitHub Pages (раздел 10) |
| `/selftest` на сайте | проверить, что классификатор даёт ожидаемые ответы на всех тестовых звуках |

## 9. GitHub: сохранить изменения

### Один раз: настроить Git

```bash
git config --global user.name "Ваше Имя"
```

```bash
git config --global user.email "почта@которая-в-github.com"
```

Почта — та же, что в аккаунте GitHub, иначе коммиты не будут привязаны к
профилю.

### Один раз: дать Git доступ к GitHub

GitHub не принимает пароль от аккаунта. Нужен **токен**:

1. GitHub → аватар → **Settings → Developer settings → Personal access
   tokens → Tokens (classic) → Generate new token**.
2. Галочка **repo**. Срок — например, 90 дней. Generate.
3. Скопировать токен сразу — второй раз он не покажется.
4. При первом `git push` Windows спросит логин и пароль: логин — имя на
   GitHub, **пароль — этот токен**. Git Credential Manager запомнит.

### Каждый раз: сохранить работу

Посмотреть, что изменилось:

```bash
git status
```

Посмотреть сами изменения:

```bash
git diff
```

Добавить всё изменённое в коммит:

```bash
git add -A
```

Сделать коммит — сообщение по-русски, одной фразой: что сделано и зачем:

```bash
git commit -m "GPS: устройство само встаёт на карту по координатам с платы"
```

Отправить на GitHub:

```bash
git push
```

Проверить: открыть https://github.com/adilzhan2012/qorgau — коммит должен
быть наверху.

### Если работаете с нескольких компьютеров

Перед началом работы — забрать чужие изменения:

```bash
git pull
```

### Что НЕ должно попадать в GitHub

Уже прописано в `.gitignore`, но проверяйте `git status` перед коммитом:

- `node_modules/`, `.next/`, `out/` — сборка, это тяжёлые временные файлы;
- `.env`, `.env.local` — локальные настройки (например, стиль карты
  `NEXT_PUBLIC_MAP_STYLE`). Если когда-нибудь появятся ключи от облака —
  им место только здесь.

Если ключ всё же закоммитили — **не** пытайтесь стереть его из истории,
просто отзовите ключ у сервиса и создайте новый.

### Если не работает

| Что пишет | Что делать |
|---|---|
| `Please tell me who you are` | не настроены `user.name` / `user.email` — выше |
| `Authentication failed` / `Support for password authentication was removed` | вместо пароля нужен токен — выше. Если старый пароль запомнился: Панель управления → Диспетчер учётных данных → Учётные данные Windows → удалить запись `git:https://github.com` |
| `! [rejected] ... (fetch first)` | на GitHub есть коммиты, которых нет у вас: `git pull`, разрешить конфликты, если есть, `git push` снова |
| `CONFLICT (content)` после pull | открыть файл, между `<<<<<<<` и `>>>>>>>` оставить нужный вариант, убрать маркеры, `git add`, `git commit` |
| `warning: CRLF will be replaced by LF` | это не ошибка, просто предупреждение про концы строк на Windows. Можно не трогать |
| `fatal: not a git repository` | вы не в папке проекта — `cd` в неё |

## 10. GitHub: опубликовать сайт

Сайт — статический, лежит в ветке `gh-pages`, откуда его отдаёт GitHub Pages.
Публикуется одной командой из папки проекта:

```bash
npm run deploy
```

Скрипт `scripts/deploy.mjs` собирает сайт (`next build` в `out/`), кладёт
результат в ветку `gh-pages` и пушит её. Через 1–2 минуты новая версия
появляется на https://adilzhan2012.github.io/qorgau/ (обновить страницу с
Ctrl+F5, если кэш).

### Один раз: включить Pages

Уже сделано для этого репозитория. Для нового:
**Settings → Pages → Source: Deploy from a branch → `gh-pages` → `/ (root)` → Save.**

### Где данные

Сервера и облака нет: список устройств, показания и журнал тревог живут в
браузере того ноутбука, где открыт сайт (`localStorage`). Ключи и аккаунты
для публикации не нужны — только токен GitHub из раздела 9.

### Порядок при обычной работе

1. Правки в коде → проверить на `npm run dev`.
2. `npm run typecheck` — без ошибок.
3. `git add -A` → `git commit -m "..."` → `git push` — сохранить исходники.
4. `npm run deploy` — обновить сайт.

Исходники (`main`) и сайт (`gh-pages`) — две разные ветки: пуш в `main`
сайт **не** обновляет, для этого нужен `deploy`.

### Если не работает

| Что | Что делать |
|---|---|
| `npm run deploy` падает на `next build` | сначала `npm run typecheck`, исправить ошибки |
| Пуш в `gh-pages` отклонён | тот же токен, что в разделе 9; токену нужна галочка **repo** |
| Сайт открывается, но старая версия | подождать 2 минуты, Ctrl+F5; проверить Settings → Pages, что источник — `gh-pages` |
| Сайт 404 | Settings → Pages: источник не выбран или выбрана не та ветка |
| На сайте нет кнопки «Подключить плату» | открыт не в Chrome/Edge |
